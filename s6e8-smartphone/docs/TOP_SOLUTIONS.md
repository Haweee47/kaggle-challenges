## 0. 결론부터 — 우리가 놓친 단 하나

우리는 **타깃 인코딩을 시도했다가 실패하고 버렸다.** 6가지 변형을 전부 시험했고
전부 기준선 아래였다(−0.00006 ~ −0.00060).

**그런데 상위권은 전부 타깃 인코딩으로 점수를 벌었다.**

| 출처 | 측정값 |
|---|---|
| post-mortem 섹션 9 | value-level 타깃 인코딩 + 모델 용량 증가 = **+0.0046** (인코딩이 2/3, 용량이 1/3) |
| 7위 Writeup | exact-value 타깃 인코딩으로 XGBoost **+0.00191** (4열 → 9열 확대 시) |
| tomasa2 노트북 | **+0.0023** |

### 왜 우리 것만 실패했나 — 한 단어 차이

> post-mortem 원문: *"Value-level encoding encodes a column's **exact value** rather than its
> **magnitude**, picking up the grid the generator rounded onto."*

우리가 만든 키:

```python
# ❌ 우리가 한 것 — 값을 '구간'으로 뭉갬
key_1d(df, col, prec=1)              # 7.37 → "7.4"   (소수 1자리로 반올림)
key_2d(df, D, S, 0.5, 0.5)           # 7.37 → 구간 14  (0.5 단위 격자)
key_2d(df, D, S, 0.25, 0.25)         # 0.25 단위 격자

# ✅ 상위권이 한 것 — 값을 '그대로'
key = df[col].astype(str)            # 7.37 → "7.37"  (정확한 값)
```

**생성기가 소수점 2자리로 반올림했다는 사실을 우리는 이미 알고 있었다.**
(01단계에서 "소수부 고유값 100개" 확인, `_dec` 피처까지 만들었다)

그런데 타깃 인코딩을 만들 때는 **그 격자를 스스로 뭉개버렸다.**

### 우리 스스로 증거를 가지고 있었다

| 우리 실험 | 키 방식 | 결과 |
|---|---|---|
| **빈도 인코딩** | `astype(str)` → **정확한 값** | **+0.00197** ✅ |
| 반올림 빈도 (Q2) | `round(1)`, `round(0)` | −0.00009 ❌ |
| 타깃 인코딩 (T1~T3) | 0.25~1.0 격자 | −0.00006 ~ −0.00060 ❌ |

**같은 데이터, 같은 아이디어인데 "정확한 값"이면 성공하고 "반올림"이면 실패한다**는
패턴이 우리 실험 안에 이미 있었다. 우리는 그 패턴을 읽지 못하고
"타깃 인코딩은 이 데이터에 안 통한다"고 결론지었다.

> **교훈: 실패한 실험은 "아이디어가 틀렸다"가 아니라 "구현이 틀렸다"일 수 있다.**
> 특히 **성공한 실험과 실패한 실험이 한 가지 요소만 다르다면**, 그 요소가 원인이다.

## 1. 1위 — Chris Deotte, "Distributed Intelligence"

**Private 0.97176 / Public 0.97207**

### 핵심 사실

| 항목 | 내용 |
|---|---|
| 방법 | **AI 에이전트 떼(swarm)** 를 돌려 모델을 자동 탐색 (NVIDIA Inference Hub) |
| 최종 제출 1 | **456개 모델 스택** + 로지스틱 회귀 결합기 → Private 0.97176 |
| 최종 제출 2 | **단일 RealMLP** CV 0.97070 / Public 0.97174 / **Private 0.97145** |

### 💥 가장 충격적인 사실

> **단일 모델 하나(RealMLP)만으로도 이 대회를 우승했을 것이다.**
> 456개 모델 앙상블이 사준 것은 **고작 +0.00031**이다.
> 본인 말로는 **18개월 만에 처음으로 단일 모델이 Playground를 이길 뻔한 사례**.

우리가 마지막 3시간을 쏟은 것: 7개 → 5개 모델 앙상블 조합 최적화 (+0.0001)
1위가 실제로 한 것: **모델 하나를 제대로 만들기**

### 결측치에 대한 그의 발언

에이전트들이 정체기에 빠졌을 때 *"결측값을 연구해봤냐"* 고 물었더니
**"새로운 신호원을 찾았다"** 고 답했고, 이후 *"에이전트들이 결측값과 관련된 많은 피처를
찾아냈고 CV와 LB가 모두 개선됐다"* 고 밝혔다.

> ⚠️ 이건 post-mortem 저자의 측정(결측 패턴은 타깃과 무관, 결측 개수 AUC 0.502)과
> 표면상 충돌한다. 저자의 해석: 저자가 반증한 것은 **결측 개수**와 **개별 열의 결측 여부**이고,
> Deotte가 말한 것은 **12개 결측 지시자의 결합 모델** 또는 **결측값 자체를 복원하는 피처**일 것이다.
> → **우리 방향(`n_missing` + 결측 복원 병기)이 맞았다는 뜻이기도 하다.**

## 2. 2위 솔루션

**한 문장과 한 피처가 전부다.**

### 그 문장

> **"I thought I needed a better blender. In fact, I needed a better model."**
> (더 좋은 블렌더가 필요한 줄 알았다. 실은 더 좋은 **모델**이 필요했다.)

이 대회 전체를 관통하는 문장이고, **우리가 마지막 4시간 동안 정확히 반대로 행동했다.**
우리는 CV 0.9682에서 정체된 뒤 조합 최적화·시드 추가·힐클라이밍에 시간을 썼다.
모델 자체를 더 좋게 만드는 데 쓰지 않았다.

### 그 피처 — 시간 예산 항등식을 "반대로" 풀기

```python
fake_daily = social_media_hours + work_study_hours + gaming_hours
```

그리고 **같은 항등식을 다른 방향으로 풀어** 세 개 열을 더 만들었다.
우리가 만든 `other_screen = daily − (social+gaming+work)`와 같은 항등식이지만,
2위는 **4가지 방향 모두**로 변형을 만들었다.

| | 우리 | 2위 |
|---|---|---|
| 제약 발견 | ✅ (60만 행 위반 0건 검증) | ✅ |
| 잔차 피처 | `other_screen` 1개 + 비율 4개 | `fake_daily` + 역방향 3개 |
| 기여 측정 | +0.00028 | 상위권의 핵심 레버 |

**post-mortem의 독립 측정**: 이 잔차의 **단독 AUC는 0.76**이다.
원본 12개 열 중 상위 3개(스크린타임) 다음, 4위에 해당한다.
전체 모델에 넣었을 때 **시드 간 편차의 약 10배** 값어치.

## 3. Post-mortem이 측정한 것 — 무엇이 통하고 무엇이 속였나

### ✅ 실제로 통한 것

| 기법 | 측정값 | 우리는? |
|---|---|---|
| **value-level 타깃 인코딩 + 용량 증가** | **+0.0046** | ❌ 구간으로 뭉개서 실패 |
| **예산 잔차 피처** (`daily − s − g − w`) | 단독 AUC 0.76, 시드편차 10배 | ✅ 했으나 변형 부족 |
| **결측값 복원** (트리가 암묵적으로 수행) | `gaming/work` 기여의 약 46% | ✅ 명시적으로 함 |

### ❌ 속인 것 — 하면 손해

| 기법 | 결과 | 이유 |
|---|---|---|
| **단조 제약**(monotone constraint) | **점수 하락** | 아래 참조 |
| MICE 등 정교한 결측 대치 | 이득 없음 | LightGBM 네이티브가 이미 충분 |
| 결측 패턴을 피처로 | 무의미 (AUC 0.502) | 결측은 라벨과 무관하게 주입됨 |
| 74개 모델 전부 균등평균 | **상위 10개 균등평균보다 나쁨** | 약한 모델이 희석 |
| LightGBM 메타모델 스태킹 | 로지스틱보다 −0.0002 | 메타 단계는 단순할수록 좋음 |

### 🤯 가장 반직관적인 발견 — "화면을 더 봐도 중독이 아닌 구간"

`social_media_hours`를 1.0~1.5시간으로 **고정**하고 `daily_screen_time`을 올리면:

```
3~4시간 →  중독률 33%
5~6시간 →  중독률 12%   ← 21%p 급락
8시간+  →  중독률 50%+
```

**중간에 깊은 골짜기가 있다.** 두 표본 절반에서 재현되고 신뢰구간이 겹치지 않는다.

**왜인가**: SNS 시간을 고정한 채 총 화면시간이 늘었다는 것은,
그 추가 시간이 **공부나 게임으로 갔다**는 뜻이다. 그건 라벨이 추적하는 대상이 아니다.

**실무적 결론**: "화면시간이 늘면 중독률도 오른다"는 것은 **주변부(marginal) 관점에서만 참**이고
**조건부로는 거짓**이다. LightGBM에 `monotone_constraints`를 걸면 **점수가 떨어진다.**

> 우리는 단조 제약을 쓰지 않았다. 운 좋게 이 함정을 피했다.

### Adversarial Validation — 경보는 진짜지만 무해했다

train과 test를 구분하는 모델을 학습하면 AUC 0.57이 나온다. 보통이면 비상이다.
그런데 **그 구분력이 전부 결측 패턴에서 나오고, 결측 패턴은 타깃과 무관**했다.
→ 재가중치나 리샘플링은 시간 낭비였다.

## 4. 리더보드 구조 — 왜 우리 "CV 신뢰" 전략이 옳았나

### Public LB는 test의 20%(59,260행)만 채점

AUC 0.971 수준에서 이 표본 크기의 **표준오차는 0.0006**이다.
상위 100팀의 점수 차이보다 크다.

### Season 6의 8개 대회 결과

| 결과 | 보드 수 |
|---|---|
| Public Top10 **전원 탈락** | 3개 |
| Public Top10 **5명 이상 생존** | 4개 |
| 1~4명 생존 | **0개** ← 중간이 없다 |

**S6E8(우리 대회)은 8명 생존**으로 "지킨 쪽"이었다.

### 하지만 조합 최적화의 이득은 환상이었다

post-mortem이 nested CV로 측정한 결과, **OOF에서 힐클라이밍으로 가중치를 찾는 것의
과적합 프리미엄은 100만분의 1 수준**이었다. 즉 힐클라이밍 자체는 부정직하지 않다.

문제는 다른 데 있었다:

> **74개 전부 균등평균 < 상위 10개 균등평균** (차이가 가중치 튜닝 이득의 10배 이상)

**모델을 많이 모으는 것보다 좋은 모델만 고르는 게 훨씬 중요했다.**
우리가 v6에서 ExtraTrees(0.962)와 GOSS를 넣었다가 단순평균이 0.9678로 떨어지고
힐클라이밍이 그 둘에 0.003 가중치를 준 것이 정확히 같은 현상이다.

| **예산 잔차 변형** | 항등식을 **4방향 모두**로 풀었어야 |
| **단일 모델 품질** | 앙상블 조합에 쓴 시간을 모델 개선에 썼어야 |
| 신경망 | sklearn MLP 대신 **RealMLP** 같은 현대 튜닝 라이브러리 |

## 6. 다음 대회에 가져갈 체크리스트

### 합성 데이터(Playground Series)를 만나면

- [ ] **원본 데이터셋을 먼저 찾는다** — 라벨 생성 규칙이 보인다
- [ ] **값의 격자를 확인한다** (`소수부 고유값 개수`) — 생성기의 반올림 흔적
- [ ] **정확한 값 기준** 빈도 인코딩 + 타깃 인코딩 (⚠️ 반올림 금지, 폴드 안에서 계산)
- [ ] 열 간 **항등식·제약**을 전수 검사한다 (`a >= b+c+d` 류)
- [ ] 찾은 제약은 **모든 방향으로** 변형을 만든다
- [ ] Adversarial validation은 돌리되, **원인이 결측 패턴이면 무시**한다

### 검증·앙상블

- [ ] **폴드 분할 시드는 절대 고정**, 모델 시드만 변경
- [ ] 조건부 분석(강한 열 고정 후 나머지 측정)으로 가짜 신호를 걸러낸다
      — 단, **여러 열의 조합 피처는 이 방법으로 안 보인다**
- [ ] 단조 제약은 **주변부 그래프만 보고 걸지 않는다** — 조건부로 확인
- [ ] 앙상블은 **좋은 모델만** 골라 넣는다 (전부 넣으면 손해)
- [ ] 메타 학습기는 **로지스틱 회귀** (LightGBM 메타는 더 나쁨)
- [ ] **모델 수를 늘리기 전에 모델 하나를 더 좋게 만든다**

### 마음가짐

- [ ] **실패한 실험 = 아이디어가 틀림**이 아니다. **구현 한 곳**을 의심하라
- [ ] 성공/실패 실험이 **한 요소만 다르면**, 그게 원인이다
- [ ] Public LB를 보고 튜닝하지 않는다 (이번에 우리가 지킨 원칙)
